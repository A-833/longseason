「漫长的季节」— GitHub Pages 部署说明
=====================================

这是一个纯静态网站，无需服务器，可直接部署到 GitHub Pages。

【部署步骤】

1. 解压本压缩包，得到全部网站文件（index.html、assets、images 等）。

2. 登录 GitHub，新建一个仓库（New repository），
   仓库名随意，例如：my-blog
   保持 Public，其他选项默认即可。

3. 在仓库页面点击 "uploading an existing file"（上传文件），
   把解压后的【所有文件和文件夹】拖进去，然后点 "Commit changes"。
   注意：要进入解压后的文件夹再全选上传，
   保证 index.html 在仓库的【根目录】下。

4. 进入仓库的 Settings → 左侧 "Pages"：
   - Source 选择 "Deploy from a branch"
   - Branch 选择 "main"，目录保持 "/ (root)"
   - 点 Save

5. 等待 1～3 分钟，刷新 Pages 页面会出现你的网址：
   https://你的用户名.github.io/my-blog/

   打开就能看到网站了。

【小技巧】
如果把仓库名直接命名为「你的用户名.github.io」，
网址会更短：https://你的用户名.github.io/

【注意事项】
- 文章、评论、点赞等数据保存在【访客自己的浏览器】里，
  你在自己电脑写的文章，别人访问时看不到；
  每个人打开都是一份独立的初始内容。
- 如果以后想要全站共享的数据（所有人看到同一批文章和评论），
  需要接入云端数据库，可以回到 Genie 里告诉我帮你升级。

【本地预览（可选）】
如果电脑上装了 Python，可以在解压后的文件夹里运行：
  python3 -m http.server 8080
然后浏览器打开 http://localhost:8080 即可本地预览。
